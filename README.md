Ralph Cifaretto is a capo of the DiMeo crime family of North Jersey in The Sopranos. Despite being born handsome instead of rich, he is a smart snappy dressing top earner with violent psycopathic tendencies. As the series progresses he comes to be reviled by virtually every character in the show as well as most viewers. He meets his end when he comes to blows with Tony, the head of the family, after the racehorse they own together dies mysteriously in a fire. 
His sirname, Cifaretto, inspired me because resembles to the seminal computer vision dataset CIFAR-10. Horse is among the class labels in CIFAR-10 and I thought it would be an interesting exercise to use adverserial learning to force a model to misclassify of an image of Ralphie as a horse. This repo explores hiow differential evolution can be employed to find perturbations to make to an image without knowing anything, namely gradients, about the model being attacked aside from the full probability vector output by the model. After attacking a model trained on CIFAR-10 the complexity of the model and accepted input size are scaled up to attack a model trained on CIFAR-100 and eventually the 1000 class Imagenet Datasets. As the the number of possible classes increased and the input size grew from 32x32 to 224x224 the number of pixels that needed to be pertrubed had to increase for the attack to be successful. While the horse class is not present in all of the datasets used to train the models being attacked, the target classes chosen for the algorithm to optimize towards is as close to a horse as possible, camel for CIFAR-100 and sorell for Imagenet.
